# orm-hibernate sample ownership

[English](README.md) | [简体中文](README.zh-CN.md)

This module supplies the Hibernate persistence provider behind the ORM API. The runnable scenario is owned by [orm](https://github.com/normlanguage/orm/tree/main/samples) in its `samples/` directory; use that example to observe the behavior through the public API.

The module identity and pinned dependencies are defined in [module.norm](../orm/hibernate/module.norm).
